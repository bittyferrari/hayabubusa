# Hayabubusa — 輕量快速看圖程式

[English](README.md) | **繁體中文**

Rust + egui 寫的單一執行檔看圖程式，支援 Windows / macOS（Linux 也可）。
目標：點圖秒開、像 XnView 一樣按 Enter 在「單圖」和「目錄縮圖」之間切換，只保留常用工具。

## 功能

- **單圖檢視**：啟動時就在背景解碼圖片（和開視窗同時進行），並預載前後張，切換幾乎無延遲
- **漫畫模式**：把資料夾裡的圖片一張接一張由上往下排成一長條、統一寬度，像看條漫 / 漫畫一樣一路往下捲，可以放大縮小（縮放比例會記住）。圖片尺寸在背景從檔頭讀取，還沒解碼前排版就是正確的。圖片直接解碼成顯示寬度的大小（JPEG 用 DCT 縮放解碼），先處理畫面上的，再往捲動方向預讀約兩個畫面，而且每一格畫面最多上傳一張新貼圖，捲動不會卡頓
- **目錄縮圖**：多執行緒產生縮圖，只處理畫面上看得到的（加上往下兩列預讀）
- **自動重新整理**：每秒在背景檢查資料夾，有檔案新增 / 刪除 / 修改（包括其他程式造成的）就自動更新，選取狀態會保留；改過的檔案會重新產生縮圖，剛複製進來、暫時被鎖住而失敗的縮圖會自動重試
- **排序**：工具列可選 名稱（自然排序）/ 修改時間 / 建立時間 / 檔案大小 / 類型，並切換遞增 / 遞減；資料夾固定排在前面，單圖模式的上下張也照這個順序，設定會記住
- **縮圖快取**：存成 WebP（品質 80、長邊 256px），一張約 2–8 KB
  - Windows：`%LOCALAPPDATA%\hayabubusa\thumbs`
  - macOS：`~/Library/Caches/hayabubusa/thumbs`
  - 以「路徑 + 檔案大小 + 修改時間」當 key，檔案改過會自動重新產生
  - JPEG 縮圖用 DCT 縮放解碼（直接以 1/8 大小解碼），速度快很多
- **剪下 / 複製 / 貼上 / 刪除**：和檔案總管共用剪貼簿，可以互相貼上；貼上和刪除透過 Windows 殼層執行（有進度視窗、同名自動改名、刪除會進資源回收筒可還原）。目前僅 Windows
- **旋轉**（左 / 右）
- **轉檔**：PNG / WEBP / JPG（可調品質，WEBP 品質 100 = 無損）
- **縮放尺寸**：百分比、長邊、限制寬高（等比）、指定寬高
- 支援讀取：jpg / png / webp / gif（第一格）/ bmp / tiff / ico / tga，會套用 EXIF 方向
- 中日韓檔名：自動載入系統字型（微軟正黑體 / Yu Gothic / Malgun Gothic / 蘋方等），韓文會自動補上韓文字型
- 可把檔案或資料夾拖進視窗開啟
- **多國語系**：繁體中文 / English / 日本語 / 한국어，預設跟隨系統語言，可在「⚙ 設定 → 語言」切換（立即生效、會記住）
- **常駐系統匣（Windows）**：關閉視窗時不真的結束，只是隱藏到右下角系統匣；之後再點圖片會直接交給常駐中的 Hayabubusa（新的 exe 找到它就立刻結束，不會再建立視窗、初始化 GPU），所以幾乎瞬間就開好
  - 預設 5 分鐘內沒再開圖就自動結束（可在「⚙ 設定」調整，0 = 不自動結束，也可以整個關掉常駐）
  - 系統匣圖示：左鍵點一下顯示視窗；右鍵選單可「開啟 Hayabubusa」或「結束」
  - 隱藏時會釋放圖片和縮圖佔用的記憶體

## 快捷鍵

### 目錄縮圖

| 按鍵 | 功能 |
|---|---|
| 方向鍵 / PageUp / PageDown / Home / End | 移動 |
| Shift + 方向鍵、Shift + 點擊 | 範圍選取 |
| Ctrl + 點擊 | 多選 |
| Ctrl + A | 全選 |
| **Ctrl + C** / **Ctrl + X** | 複製 / 剪下選取的檔案或資料夾，可到檔案總管或桌面貼上（剪下的項目會變淡） |
| **Ctrl + V** | 把剪貼簿裡的檔案（從 Hayabubusa 或檔案總管複製 / 剪下的）貼到目前資料夾 |
| **Delete** | 把選取的項目移到資源回收筒 |
| **Enter** / 雙擊 | 開啟圖片或進入資料夾 |
| Backspace | 上一層 |
| F5 | 重新整理（清單和縮圖全部重新載入，單圖模式也可用） |
| 右鍵 | 開啟 / 剪下 / 複製 / 貼上 / 刪除 / 旋轉 / 轉換選單 |
| 滾輪 | 捲動（一格捲幾列可在「⚙ 設定」調整） |
| Ctrl + 滾輪 | 調整縮圖大小 |

工具列的「左轉 / 右轉」會**直接覆寫**選取的檔案。

### 單圖檢視

| 按鍵 | 功能 |
|---|---|
| **Enter** / Esc | 回到目錄縮圖（游標會停在目前這張） |
| → ↓ PageDown 空白鍵 / 滾輪往下 | 下一張 |
| ← ↑ PageUp Backspace / 滾輪往上 | 上一張 |
| Home / End | 第一張 / 最後一張 |
| Ctrl + 滾輪、+ / - | 縮放（以滑鼠位置為中心） |
| 拖曳 | 平移 |
| 0 或 Z | 符合視窗 |
| 1 | 100% |
| R / L（或 Shift+R） | 右轉 / 左轉（先預覽） |
| **Ctrl + S** | 儲存旋轉 |
| Ctrl + C | 複製目前這張圖（檔案），可到桌面貼上 |
| Delete | 把目前這張移到資源回收筒，並跳到下一張 |
| C | 轉換 / 縮放 對話框 |
| F、F11、雙擊 | 全螢幕 |

在單圖模式旋轉只是預覽，按 Ctrl+S 才會寫入檔案；沒存就換下一張會捨棄。

### 漫畫模式

在單圖檢視按 **M**（或工具列「📖 漫畫模式」），或在目錄縮圖工具列按「📖 漫畫模式」（從選取的那張開始）。開啟後，之後點開圖片也會用漫畫模式，直到按 M 切回單張。

| 按鍵 | 功能 |
|---|---|
| 滾輪 / ↑ ↓ | 捲動（一格捲多少可在「⚙ 設定」調整） |
| PageDown / 空白鍵、PageUp / Shift+空白鍵 | 捲動一個畫面 |
| → / ←（Backspace） | 下一張 / 上一張（對齊到圖片頂端） |
| Home / End | 最前面 / 最後面 |
| Ctrl + 滾輪、+ / -、工具列 − + | 縮放（以滑鼠位置為中心，會記住） |
| 0 或 Z | 符合寬度 |
| 1 | 100%（以目前這張為準） |
| 拖曳 | 捲動 / 平移 |
| **M** | 切回單張檢視（停在目前這張） |
| **Enter** / Esc | 回到目錄縮圖 |
| Ctrl + C、Delete、C、F / F11 / 雙擊 | 和單圖檢視相同，作用在目前這張 |

「目前這張」是畫面上方約三分之一處的那張圖，Enter / M / Delete / Ctrl+C 都以它為準。

## 設定

目錄縮圖工具列的「⚙ 設定」：

- 介面語言（跟隨系統 / 繁體中文 / English / 日本語 / 한국어）
- 滾輪一格捲動幾列縮圖（預設 1 列）、平滑捲動開關
- 漫畫模式滾輪一格 / 方向鍵捲動幾 px（預設 150 px；漫畫模式工具列也有「⚙ 設定」）
- 刪除前確認（預設開啟；確認視窗勾「以後不要再問」也會關掉）
- 開啟時視窗：記憶上次的狀態（大小 / 位置 / 最大化，第一次預設最大化）或總是最大化
- 關閉視窗後常駐在系統匣（預設開啟，Windows），以及幾分鐘沒開圖就自動結束（預設 5 分鐘）

設定檔：Windows `%APPDATA%\hayabubusa\settings.txt`、macOS `~/Library/Application Support/hayabubusa/settings.txt`

## 編譯

### Windows

1. 安裝 [Rust](https://rustup.rs/)（安裝程式會提示裝 Visual Studio C++ Build Tools，照著裝即可）
2. 在此資料夾執行：

   ```
   cargo build --release
   ```

3. 產出：`target\release\hayabubusa.exe`（單一檔案，約 10 MB，可以複製到任何地方）

**設為預設看圖程式**：對任一 jpg 按右鍵 →「開啟檔案」→「選擇其他應用程式」→ 選 `hayabubusa.exe` → 勾「一律使用」。png / webp 各做一次。

### macOS

```
cargo build --release
./target/release/hayabubusa 圖片.jpg
```

注意：在 macOS 從 Finder「打開方式」需要包成 `.app` 並處理 Apple 的開檔事件，目前版本還沒做；可以用拖曳檔案到視窗或命令列開啟。

### 用 GitHub 自動編譯

把 `github-build.yml` 移到 `.github/workflows/build.yml`，再把資料夾推上 GitHub，就會自動編出 Windows 與 macOS（Intel / Apple Silicon）版本，在 Actions 頁面下載。

## 注意事項

- 旋轉和覆寫會重新編碼：JPEG 以品質 95 存檔，EXIF 等中繼資料不會保留
- 檔案先寫到暫存檔再改名取代，寫入失敗不會毀損原檔
- 清除縮圖快取：直接刪掉上面的 thumbs 資料夾

## 程式結構

```
src/main.rs     啟動：解析參數、提早開始解碼、開視窗
src/app.rs      介面：目錄縮圖、單圖檢視、對話框
src/app/comic.rs 漫畫模式（所有圖片垂直排列）
src/workers.rs  背景執行緒池（最新需求優先，捲走的工作自動丟棄）與縮圖快取
src/decode.rs   解碼、EXIF 方向、JPEG 快速縮圖、WebP 編解碼
src/ops.rs      旋轉 / 轉檔 / 縮放 / 批次處理
src/fonts.rs    依語言載入系統中日韓字型
src/i18n.rs     多國語系：語言偵測與各語言字串
src/clipboard.rs 系統剪貼簿的檔案清單（Windows CF_HDROP）
src/fileops.rs  複製 / 移動 / 刪除到資源回收筒（Windows SHFileOperation）
src/resident.rs 常駐系統匣、單一執行個體（WM_COPYDATA 轉交路徑）、閒置自動結束
src/util.rs     自然排序（img2 < img10）、雜湊、設定檔
```
